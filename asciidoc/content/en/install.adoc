== Marketplace (HACS)

Since Home Assistant 2026.11, HACS is called _Marketplace_ and is built in:
_Settings → Marketplace_ (administrators only). On older versions the same
steps apply in HACS.

[arabic]
. In the Marketplace, search for _EnerLens_, install, reload the browser
. The Marketplace registers the resource
`/local/community/enerlens-card/enerlens-card.js` for you (HACS before 2026.11:
`/hacsfiles/enerlens-card/enerlens-card.js`, which keeps working); if the card
does not appear, check _Settings → Dashboards → Resources_

== Update

The Marketplace only checks for new releases now and then. To get one at once:

[arabic]
. Open the Marketplace, tab _Installed_, on _EnerLens_ choose ⋮ →
_Update information_
. The update appears under _Settings → Updates_ (or in the Marketplace at the
card) → install it
. After installing, be sure to reload the browser. A card runs in the browser,
not in Home Assistant itself; without a reload the browser keeps showing the
old version from its cache. In the Home Assistant app, pull the page down until
it reloads, or restart the app

== Without the Marketplace

[arabic]
. Download `enerlens-card.js` from the latest release
. Copy it to `config/www/`
. Add the resource under _Settings → Dashboards → Resources_:
`/local/enerlens-card.js?v=1` as _JavaScript module_

With every update replace the file and raise the number after `?v=` - otherwise
the browser keeps loading the old file from its cache.
