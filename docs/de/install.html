Installation

HACS

  1. In HACS nach EnerLens suchen, installieren, Browser neu laden
  2. HACS trägt die Ressource /hacsfiles/enerlens-card/enerlens-card.js selbst ein; erscheint die Karte nicht, unter Einstellungen → Dashboards → Ressourcen nachsehen

Update

HACS sieht nur in Abständen nach, ob es ein neues Release gibt. Sofort geht es so:

  1. HACS öffnen, bei EnerLens auf ⋮ → Informationen aktualisieren
  2. Das Update erscheint unter Einstellungen → Updates (oder in HACS bei der Karte) → installieren
  3. Nach der Installation unbedingt den Browser neu laden. Eine Karte läuft im Browser, nicht in Home Assistant selbst; ohne Neuladen zeigt er weiter die alte Version aus seinem Zwischenspeicher. In der App von Home Assistant die Seite nach unten ziehen, bis sie neu lädt, oder die App neu starten

Ohne HACS

  1. enerlens-card.js aus dem letzten Release herunterladen
  2. Nach config/www/ kopieren
  3. Unter Einstellungen → Dashboards → Ressourcen eintragen: /local/enerlens-card.js?v=1 als JavaScript-Modul

Bei jedem Update die Datei ersetzen und die Zahl hinter ?v= erhöhen - sonst lädt der Browser die alte Datei aus seinem Zwischenspeicher.
