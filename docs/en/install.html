Installation

HACS

  1. HACS → ⋮ → Custom repositories → add https://github.com/wawersich/enerlens-card, type Dashboard
  2. Search for EnerLens, install, reload the browser
  3. HACS registers the resource /hacsfiles/enerlens-card/enerlens-card.js for you; if the card does not appear, check Settings → Dashboards → Resources

Manually

  1. Download enerlens-card.js from the latest release
  2. Copy it to config/www/
  3. Add the resource under Settings → Dashboards → Resources: /local/enerlens-card.js as JavaScript module
